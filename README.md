# Corpus — Personal Health OS prototype

Corpus is a mobile-first interface prototype for personal health tracking. The profile, logs, reports, goals, and settings screens are included.

## Run locally

Open `index.html` in a modern browser, or publish the files in this folder with GitHub Pages. GitHub Pages can host the interface as a static site.

## Prototype limitations

The analysis features expect an `/api/analysis` backend, which is not included in this repository. Data persistence also requires a storage backend. Those features need backend work before they can operate as a complete hosted app.

## Files

- `index.html` — application interface and interactions
- `icon.svg` — app icon artwork
